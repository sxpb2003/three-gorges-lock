# 三峡永久船闸 · 三维模型（结构基准 + 锚固模型）

两个页面：

- `index.html`（默认）：结构基准模型（轮廓、边坡、中隔墩、闸墙、底板、闸首、人字门、输水系统、排水洞、两侧山体），不含锚固件，GLB 约 4.7 MB。
- `anchorage.html`：锚固模型（结构体块 + 锚索 1862 束、锁口锚杆 11232 根、高强锚杆抽样 5048 根、锚桩 121、排水孔 566、系船柱、分区线），GLB 约 32 MB。

数据来源：21 张施工图 DWG + 《全衬砌船闸设计》《船闸与升船机设计》及 520 篇论文。
坐标：X=桩号 14950~16660 m，Y 以中隔墩中心为 0，Z=高程（m）。

three.js r160 已放本地 vendor/，离线可用。
